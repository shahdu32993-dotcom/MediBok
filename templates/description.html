1. Application Overview

MediBook is a hospital appointment management system built with Flask and MySQL. It supports three user roles — Patient, Doctor, and Admin — each with distinct capabilities.

  • Patients can register, browse doctors and departments, book appointments, and message their doctors.
  • Doctors can view their schedule, confirm appointments, see their patients, and reply to messages.
  • Admins manage all users, appointments, and can add new doctors to the system.
